Persistência em JSON

Ainda não há ficheiro JSON ligado; os dados ficam guardados apenas neste navegador.

Para guardar os dados que já estão neste navegador, usa “Guardar dados atuais num JSON” e seleciona o ficheiro da base de dados. A partir daí, cada alteração é escrita nesse ficheiro. “Ler e ligar” carrega o conteúdo do ficheiro para a aplicação. GitHub Pages não pode escrever diretamente no JSON do repositório.

Acesso e palavra-passe

O login é uma proteção simples nesta página. Os dados e a palavra-passe ficam neste navegador; não há uma conta de servidor nem encriptação de acesso. Para maior privacidade, mantém o dispositivo e a conta do sistema protegidos e não publiques esta página.
